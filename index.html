About

I build backend systems and AI tooling, mostly in Python and TypeScript. My focus is the layer between a language model and something that actually has to work: tool calls, state, constraints, and APIs that stay up.

Recent work includes FestOS, an agentic campus-fest planner built for the Qloo Agentic Hackathon — it converts taste signals and a budget into a full event lineup — and a set of MCP servers that let assistants call real tools. I mostly learn by shipping: hackathons, open source, and small tools that solve something I run into.

I'm a second-year computer science student in Kanpur. Most of what I know came from building rather than coursework.
